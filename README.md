# A~C 自然發音 × 交通工具

給英文老師用的互動式自然發音教材。單一 HTML 檔，離線也能用。

🌐 線上版：https://u11410010-dotcom.github.io/abc/

## 單字（24 個，全部 A / B / C 開頭）

- **Aa /æ/**：ambulance 救護車、accident 車禍、airbag 安全氣囊、axle 車軸、amber 黃燈
- **Bb /b/**：bus 巴士、bicycle 腳踏車、bike 單車、boat 小船、balloon 熱氣球、bobsled 雪橇、belt 安全帶、battery 電池、bag 行李袋
- **Cc /k/**：car 汽車、coach 遊覽車、canoe 獨木舟、cart 手推車、cabin 客艙、cargo 貨物、caravan 拖掛車、camper 露營車、cockpit 駕駛艙、carriage 馬車

## 三大功能

| 功能 | 說明 |
|---|---|
| 📇 **單字卡** | 點卡片唸單字、0.45× 超慢速、🔤 逐音、🎙 老師錄音、✅ 標記已學會 |
| 🎧 **聽音選字** | 10 題、4 選 1，可按鍵盤 1~4 作答 |
| 🖼 **看圖配字** | 圖文配對遊戲，計步數 |

## 自然發音重點：字母名 ≠ 字母音

| | 字母名 | 字母音（拼讀時要唸的） |
|---|---|---|
| A | /eɪ/ 欸 | **/æ/ 艾** |
| B | /biː/ 必 | **/b/ 波阿（buh）** |
| C | /siː/ 西 | **/k/ 可阿（cuh）** |

「🔤 逐音」會依序唸：**① 開頭字母名 → ② 該單字的實際首音 → ③ 慢速整字 + 正常整字**。

## 老師使用說明

**右上角設定**：發音音色、速度（0.4×～1.15×）、口音（美式／英式）。

**如果沒聲音**：
1. 按 **🔈 試聽**，看 **🔊 狀態** 顯示什麼
2. 「找不到英文語音」→ 改用 Chrome/Edge 並安裝語音套件
   - Windows：設定 → 時間與語言 → 語音 → 新增 English (United States)
3. 還是沒聲音 → 用 **🎙 錄音**錄一次，之後都用你的真人聲音

> 🎙 錄音存在各人瀏覽器本機（localStorage），不會上傳。

**建議流程**：讀 Aa 組 → 🔤 逐音拆解 → 🎧 聽音選字 → 🖼 看圖配字。
